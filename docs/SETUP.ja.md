# セットアップガイド(初めての方向け)

[한국어](SETUP.ko.md) · [English](SETUP.en.md) · **日本語**

順序は **WSL2 の確認 → ツールの取得 → `setup.sh` を一度 → 起動** です。コマンドはすべて **WSL(Ubuntu)ターミナル**に入力します。
急ぐ場合は [README のクイックスタート](../README.ja.md#クイックスタート)の 2 行で十分です。このガイドは各段階で何を確認するかを説明します。

---

## 0. このツールは何? / 必要なもの

`~/projects` 内のプロジェクトをウェブ画面(ダッシュボード)で見て、ボタン一つでそのフォルダーから **Claude Code** を新しいターミナルウィンドウで起動する個人用ローカルツールです。

| 必要なもの | 理由 | 無い場合 |
|---|---|---|
| **Windows 10/11 + WSL2** | `wsl.exe`・`powershell.exe` でウィンドウを開く → **Mac・通常の Linux では動きません** | 1 でインストール |
| WSL 内の **Node.js 20 以上** | サーバーの実行 | `setup.sh` が nvm でのインストールを提案 |
| WSL 内の **Claude Code CLI**(`claude`) | このツールが起動する対象 | `setup.sh` がインストールを提案 |
| (任意)**GitHub CLI**(`gh`)ログイン済み | カードの公開/非公開バッジ、「プロジェクト名変更」で GitHub リポジトリ名も変更 | 無くても動作(バッジは `?`、名前変更はローカルのみ) |

---

## 1. WSL2 があるか確認(無ければインストール)

**Windows PowerShell**(WSL ではない)を開いて:

```powershell
wsl --version
```

- バージョンが表示される → WSL2 あり。次へ。
- エラーになる → 管理者 PowerShell で `wsl --install` を実行し、**PC を再起動**、Ubuntu の初期設定(ユーザー名・パスワード)を済ませます。

> 💡 **「WSL(Ubuntu)ターミナル」とは?** スタートメニューで **「Ubuntu」** を検索してクリックすると開く黒いウィンドウです。プロンプトが `名前@コンピューター:~$` の形なら正しく入れています。PowerShell(`PS C:\>`)・コマンドプロンプトとは別のウィンドウです。PowerShell で `wsl` と打っても同じ Ubuntu に入れますが、その場合 `/mnt/c/...`(Windows のフォルダー)から始まることがあるので `cd ~` で Linux のホームへ移動してください。

ここからは **WSL(Ubuntu)ターミナル**で進めます。

---

## 2. ツールの取得

> ⚠️ **必ず WSL ターミナルの中でクローンしてください。** PowerShell・エクスプローラーからクローンすると `.sh` が Windows の改行(CRLF)で保存され、スクリプトが `set: pipefail: invalid option name` で失敗します。(`setup.sh` がこれも点検・修正します。)

```bash
cd ~                 # ツールはスキャン対象の外に(ホームなど — ~/projects の中には置かない)
git clone https://github.com/GojoSuperman/claude-wsl-launcher.git
cd claude-wsl-launcher
```

---

## 3. `setup.sh` を一度

```bash
bash scripts/setup.sh
```

何をするか:

| # | 点検 | 問題があれば |
|---|---|---|
| 1 | WSL 内か、`powershell.exe`・`wsl.exe` にアクセスできるか | 原因と対処を案内 |
| 2 | Node.js 20 以上 | 「nvm でインストールしますか? [Y/N]」 |
| 3 | `claude` が **Linux 側(nvm)** にあるか — ショートカットが実際に探す方法そのまま | 「インストールしますか? [Y/N]」(`npm install -g @anthropic-ai/claude-code`) |
| 4 | (任意)`gh` のログイン状態 | 案内のみ |
| 5 | `scripts/*.sh` の改行が LF か | 「直しますか? [Y/N]」 |
| 6 | 依存関係(`node_modules`) | 無ければ `npm install` |
| 6.5 | **プロジェクトフォルダー**: ホーム配下で git リポジトリを複数含むフォルダーを探して番号で表示 | 選んだフォルダーを `~/.config/project-launcher/config.json` に保存。候補が無ければ `~/projects` を作成 |
| 7 | デスクトップのショートカット | 「作りますか? [Y/N]」 |

- すべての質問はそのまま Enter で「いいえ」です。飛ばしたものは後で `bash scripts/setup.sh` を再実行すれば続きから行えます。
- すでに使っているプロジェクトフォルダー(`~/dev`、`~/work` など)があれば、候補一覧にリポジトリ数付きで表示されます。番号を選ぶだけです。後でダッシュボード上部の **[変更]** で変えられます。
- 質問なしで終えるには(AI エージェント・スクリプト): `bash scripts/setup.sh --yes` — すべて「はい」、フォルダーはリポジトリが最も多い候補を自動選択。
- フォルダーを直接指定するには: `PROJECTS_ROOT=~/dev bash scripts/setup.sh`。
- ショートカット名を変える: `SHORTCUT_NAME='マイランチャー' bash scripts/setup.sh`(既定 `Claude WSL Launcher`)。
- 最後に `✅` と接続先 URL が表示されれば完了です。

> このツールは**ツールの置き場所とは無関係に**選んだプロジェクトフォルダーをスキャンします。各サブフォルダーがカードになります。優先順位: `PROJECTS_ROOT` 環境変数 > 設定ファイル > `~/projects`。

## 4. 起動

**デスクトップのショートカットをダブルクリック**すると:

- サーバーを**バックグラウンド**で起動し、**ブラウザだけ**を開きます(余分なターミナルウィンドウなし)。Chrome があれば**アドレスバーのないアプリ風ウィンドウ**、無ければ既定ブラウザのタブで開きます。
- サーバーの起動に**失敗したときだけ**ターミナルウィンドウが出てログを表示します。
- すでに起動していれば、再起動せずブラウザだけ開きます。

ターミナルから直接起動する場合:

```bash
npm start       # 最後に「프로젝트 런처: http://127.0.0.1:41730」が出れば成功
```

- ポートが使用中なら 41731〜41739 に自動フォールバックするので、ログに出た実際のアドレスを開きます。指定: `PORT=5000 npm start`
- プロジェクトフォルダーの変更: ダッシュボード上部の **スキャンフォルダ [変更]**(設定ファイルに保存、再起動不要)。カードが一つも無いときはバナーからも変更できます。一度だけ別フォルダーで起動するには `PROJECTS_ROOT=~/dev npm start`(その間 [変更] はロック)。
- **停止**: ダッシュボードのウィンドウを閉じると約 10 秒後にサーバーが**自動停止**します。すぐ止めるにはヘッダーの **[サーバー停止]** ボタンかターミナルで `Ctrl+C`。(自動停止を無効にするには `AUTO_SHUTDOWN=0 npm start`)

## 5. 使い方

| ボタン | 動作 |
|---|---|
| **[claude 起動]** | そのフォルダーで**新しい WSL ウィンドウ**に claude。会話履歴があれば続き(`--continue`)、無ければ新規セッション |
| **[リモート確認]** → **[取得]** | `git fetch` 後、遅れていれば `git pull --ff-only`(upstream のあるカードにのみ表示) |
| **[+ 新規プロジェクト]** | `~/projects/<名前>` を作成し `git init` |
| **[✏️ プロジェクト名変更]** | フォルダー名を変更し、claude の履歴フォルダーも一緒に移動。origin が GitHub なら `gh repo rename` でリポジトリ名と remote URL も更新(gh ログインが必要。失敗時はローカルのみ変更し警告)。実行中のプロジェクトとこのツール自身のフォルダーではボタン無効 |
| カードの **GitHub 行** | origin リポジトリ(`owner/repo`)と**公開/非公開**バッジ。gh 未ログインなら `?`。バッジをクリックすると確認後に公開↔非公開を切替(リポジトリの管理者権限が必要) |
| **自動 · ☀️ · 🌙** | ライト/ダークテーマ。自動 = Windows 設定に従う(記憶されます) |
| **[❓ ヘルプ]** / `?` キー | 使い方モーダル |
| 下部の**サーバーコンソール** | このサーバーのログ(読み取り専用)。▾ で折りたたみ/展開 |

- **名前の規則**: 新規作成・名前変更とも**英数字・`-`・`_`・`.` のみ**(GitHub リポジトリの規則)。それ以外を入力すると案内が出て中止します。
- 名前変更の前に「他の claude ウィンドウでこのフォルダーを編集中でないか」の確認が一度出ます。別フォルダーから起動した claude がこのフォルダーを編集している場合は自動検出されません。
- 別の PC でも使うには、その PC で 2・3 をもう一度行ってください。コードは git で取得できますが、Node・claude のインストールとショートカットは PC ごとに必要です。

## 6. トラブルシューティング

まずこれを実行してください。ほとんどはここで原因とコマンドが分かります:

```bash
bash scripts/doctor.sh        # 診断のみ
bash scripts/doctor.sh --fix  # 確認のうえ自動修正
```

doctor で捕まえられないもの:

| 症状 | 対処 |
|---|---|
| ブラウザで「接続できません」 | サーバーが起動していないか自動停止した。ショートカットを再度ダブルクリック、または `npm start`。 |
| `claude 起動` を押してもウィンドウが出ない / "spawn powershell.exe ENOENT" | PATH の問題。WSL ターミナルから `npm start`(ログインシェル)でサーバーを起動してみてください。 |
| ポート使用中(EADDRINUSE) | すでにサーバーが起動中。[サーバー停止] するか `PORT=5000 npm start`。 |
| ショートカットが古い動作をする / 動かない | `bash scripts/install-shortcut.sh` で再作成。 |
| 名前変更後に「GitHub の名前変更に失敗」の警告 | ローカルは変更済み。`gh auth login` 後に再試行するか、GitHub ウェブで名前を変えて `git remote set-url origin <新しい URL>`。 |

## 7. セキュリティを一行で

このサーバーは **自分の PC(localhost)専用**で認証がありません。**外部に公開しないでください**(ポートフォワーディング・`0.0.0.0` バインド禁止)。個人用ローカルツールとしてのみ使ってください。

## 付録. 手動でインストールしたい場合

`setup.sh` を使わずに自分で行う場合のコマンドです。

**WSL 環境の確認**

```bash
echo "ディストリ: $WSL_DISTRO_NAME"   # 例: Ubuntu-24.04
echo "ユーザー: $(whoami)"            # 例: alice
echo "ホーム: $HOME"                  # 例: /home/alice
```

(これらは自動検出されるため、どこにも入力しません。)

**Node.js**

```bash
node -v    # v20.x 以上なら OK。無い/古い場合:
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# ターミナルを閉じて開き直してから:
nvm install --lts
```

**Claude Code CLI**

```bash
claude --version   # 無ければ:
npm install -g @anthropic-ai/claude-code
# インストール後 claude を一度実行してログイン。最新のインストール方法は Claude Code 公式ドキュメントを優先してください。
```

**依存関係・実行・ショートカット**

```bash
npm install
npm start                               # または
bash scripts/install-shortcut.sh        # デスクトップのショートカット(PROJECTS_ROOT=~/dev でスキャンフォルダー指定可)
```

**改行が壊れたとき**(`set: pipefail: invalid option name`): WSL 内で `sed -i 's/\r$//' scripts/*.sh`、または WSL ターミナルからクローンし直してください。
