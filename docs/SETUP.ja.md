# セットアップガイド（完全初心者向け）

[한국어](SETUP.ko.md) · [English](SETUP.en.md) · **日本語**

初めての方でも迷わないよう、**自分の環境を確認 → 必要なものをインストール → 起動する** まで、段階的に案内します。
コマンドはすべて **WSL（Ubuntu など）のターミナル** に入力してください。

---

## 0. このツールは何ですか？ / 自分に合っていますか？

`~/projects` フォルダー内のプロジェクトをウェブ画面（ダッシュボード）で確認し、ボタン一つでそのフォルダーから **Claude Code** を新しいターミナルウィンドウに起動する個人用ローカルツールです。

**必要な環境（3つすべてが必要です）：**

| 必要なもの | 理由 |
|---|---|
| **Windows 10/11 + WSL2** | `wsl.exe`・`powershell.exe` でウィンドウを起動する → **Mac・通常の Linux では動作しません** |
| WSL 内に **Node.js 20 以上** | サーバーを実行するため |
| WSL 内に **Claude Code CLI**（`claude`） | このツールが起動する対象 |

> Mac／ネイティブ Linux のユーザーはこのツールを使用できません（Windows 専用コマンドに依存しているため）。

---

## 1. WSL2 の確認（なければインストール）

**Windows PowerShell**（WSL ではありません）を開き、次を実行します：

```powershell
wsl --version
```

- バージョン情報が表示された → WSL2 あり。次の手順へ。
- エラーが出る、またはインストールされていない → 管理者 PowerShell で：
  ```powershell
  wsl --install
  ```
  インストール後、**PC を再起動**し、Ubuntu の初期設定（ユーザー名・パスワード）を完了させます。

これ以降は **WSL（Ubuntu）のターミナル** を使います。（スタートメニューで "Ubuntu" を検索）

> 💡 **「WSL（Ubuntu）ターミナル」とは？** スタートメニューで **「Ubuntu」** を検索してクリックすると開く黒い画面です（Ubuntu Linux が動くターミナル）。プロンプトが `名前@コンピューター:~$` の形なら正しく入れています。PowerShell（`PS C:\>`）やコマンドプロンプトとは別のウィンドウです。PowerShell で `wsl` と入力しても同じ Ubuntu に入れますが、その場合 `/mnt/c/...`（Windows フォルダー）から始まることがあるので、`cd ~` で Linux のホームに移動してください。

---

## 2. 自分の WSL 環境を確認する

WSL ターミナルで以下を入力して、自分の値を確認します（設定には使いませんが、どんな環境か把握しておくと便利です）：

```bash
echo "배포판: $WSL_DISTRO_NAME"   # 例: Ubuntu-24.04
echo "사용자: $(whoami)"           # 例: alice
echo "홈: $HOME"                   # 例: /home/alice
```

> このツールは上記の値を **自動検出** するため、手動で入力する必要はありません。（どの PC でもそのまま動作します）

---

## 3. Node.js の確認 / インストール

```bash
node -v    # v20.x 以上であれば OK
```

- `command not found` または 20 未満の場合は、**nvm** でのインストールを推奨：
  ```bash
  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
  # ターミナルを一度閉じて開き直してから：
  nvm install --lts
  node -v
  ```

---

## 4. Claude Code CLI の確認 / インストール

```bash
claude --version   # バージョンが表示されれば OK
```

- ない場合は **Claude Code 公式インストール案内** に従ってインストールします（最も一般的な方法）：
  ```bash
  npm install -g @anthropic-ai/claude-code
  ```
  インストール後、`claude` で一度ログイン／設定を完了し、`claude --version` で確認します。
  > 最新のインストール方法は、必ず Claude Code 公式ドキュメントを優先してください。

---

## 5. このツールを取得する

> ⚠️ **必ず WSL（Ubuntu）ターミナル内でクローンしてください。** Windows PowerShell やエクスプローラーからクローンすると、git が `.sh` ファイルを Windows の改行コード（CRLF）で保存し、後のショートカット作成（7番）が `set: pipefail: invalid option name` で失敗します。

```bash
cd ~                 # ツールはスキャン対象フォルダーの外に（ホームなど — ~/projects の中に置かない）
git clone https://github.com/GojoSuperman/claude-wsl-launcher.git
cd claude-wsl-launcher
mkdir -p ~/projects  # スキャンする既定フォルダー（無い場合のみ）
```

> `~/projects` がこのツールのスキャン対象となる既定フォルダーです（**ツールの設置場所とは別**）。作業中のプロジェクトをそこに置くとカードとして表示されます。別のフォルダーを使うには手順 6 の `PROJECTS_ROOT` を参照。

---

> 💡 **セットアップ点検（推奨）：** クローン後に `bash scripts/doctor.sh` を実行すると、WSL/Node/claude/改行コード/依存関係を自動点検し、直すべき項目があれば正確なコマンドを教えてくれます。**claude がその PC の WSL（nvm）にインストールされているか**をショートカットのランチャーと同じ方法で確認するので、**別の PC で取得したとき**に最初に実行すると便利です。 診断だけでなく**自動で修正させるには** `bash scripts/doctor.sh --fix` — 不足項目ごとに「インストールしますか？ [Y/N]」と尋ね、同意したものだけ修正します。

## 6. インストールして起動する

```bash
npm install     # 依存関係をインストール（初回のみ）
npm start       # サーバーを起動
```

最後に `프로젝트 런처: http://127.0.0.1:41730` と表示されれば成功です。（ポートが使用中なら 41731 以降に自動フォールバックするので、ログに表示された実際のアドレスを開いてください。）
ブラウザで **http://127.0.0.1:41730** を開いてください。

- ポートを変更するには: `PORT=5000 npm start`
- **スキャンするフォルダを変更するには**（既定の `~/projects` ではなく既存の作業フォルダを使う）: `PROJECTS_ROOT=~/dev npm start`
  - 絶対パス（`/home/me/work`）・`~/サブ`・ホーム基準の相対パス（`repos`）に対応。
- 停止するには: 画面ヘッダーの **[서버 종료]**（サーバー終了）ボタン、またはターミナルで `Ctrl+C`。

---

## 7. （オプション）デスクトップショートカットを作成する

毎回ターミナルを開かずに、ダブルクリックで起動したい場合：

```bash
bash scripts/install-shortcut.sh
```

**`~/projects` 以外のフォルダ**をスキャンさせるには、作成時にそのフォルダを指定します（値がショートカットに焼き込まれます）：

```bash
PROJECTS_ROOT=~/dev bash scripts/install-shortcut.sh   # ダブルクリックで ~/dev をスキャン
```

デスクトップにショートカットが作成されます。ダブルクリックすると：
- サーバーを **バックグラウンド** で起動し、**ブラウザだけ** を開きます（別途ターミナルウィンドウは開きません）。
- サーバーの起動に **失敗した場合のみ** ターミナルウィンドウが表示されてログを確認できます（原因確認用）。
- 指定したスキャンフォルダ（未指定なら `~/projects`）で起動します。
- 別の PC に clone した場合は、その PC でもこのコマンドを **もう一度** 実行して、そちらのデスクトップにもショートカットを作成してください。

> ショートカット名は既定で **`Claude WSL Launcher`** です。別の名前にするには（同名の既存ショートカットを上書きしないように）: `SHORTCUT_NAME='My Launcher' bash scripts/install-shortcut.sh`

---

## 8. 使い方まとめ

- **カードの [claude 실행]**（claude 実行）ボタン → そのフォルダーで **新しい WSL ウィンドウ** に claude を起動。会話履歴があれば続きから（`--continue`）、なければ新規セッション。
- **下部サーバーコンソール** → このサーバーのログ（読み取り専用）。「サーバーが動いている」ことを確認できます。▾ で折りたたみ／展開。
- **[서버 종료]**（サーバー終了）→ ローカルサーバーを停止します。（ショートカットでバックグラウンド起動した場合の終了手段です）
- **[원격 확인]**（リモート確認）/ 取得 → `git fetch` 後、遅れていれば `git pull --ff-only`。
- **[+ 새 프로젝트]**（新しいプロジェクト）→ `~/projects/<名前>` フォルダーを作成し `git init`。

## 9. トラブルシューティング

| 症状 | 解決策 |
|---|---|
| ブラウザで「接続できない」 | サーバーが起動していないか終了しています。ターミナルで `npm start` を再実行するか、ショートカットをダブルクリックし直してください。 |
| `claude 실행` を押してもウィンドウが開かない、または "spawn powershell.exe ENOENT" | ほぼ PATH の問題です。このツールは自動フォールバックを試みますが、それでも駄目な場合は WSL ターミナルから `npm start`（ログインシェル）でサーバーを起動してみてください。 |
| 新しいウィンドウで `claude: command not found` | WSL に claude がインストールされていません。ランチャー（`scripts/launch-claude.sh`）は nvm を直接読み込んで claude を探すため、**既定の nvm Node** にインストールしてください（手順 4）：`npm install -g @anthropic-ai/claude-code`。コードは git で同期されますが claude のインストールは PC ローカルなので、**PC ごとに一度** 必要です。 |
| ポートが使用中（EADDRINUSE） | すでにサーバーが起動しています。既存のサーバーを [서버 종료]（サーバー終了）するか、`PORT=5000 npm start` を使用してください。 |
| ショートカットが古い動作をする／動かない | `bash scripts/install-shortcut.sh` を再実行してショートカットを再作成してください。 |
| `set: pipefail: invalid option name` / `invalid option name`（文字が重なって崩れて見える） | `.sh` が Windows の改行コード（CRLF）になっています。**WSL 内で** `sed -i 's/\r$//' scripts/*.sh` で修正するか、WSL ターミナルから再クローンしてください（5番）。 |

## 10. セキュリティについて（一言）

このサーバーは **自分の PC（localhost）専用** で、認証はありません。**外部に公開しないでください**（ポートフォワーディング・`0.0.0.0` バインディングは禁止）。個人用ローカルツールとしてのみご使用ください。
